# `@antica-labs/b2a-skills` — Open-Source Methodological B2A Skills (`Apache-2.0`)

Four open-source methodological skills teaching autonomous agents (`Claude`, `ChatGPT`, `Gemini / Antigravity`, `Cursor`, `Codex`) deterministic **Business-to-Agent (B2A)** verification and zero-copy URN orchestration across sovereign European MCP endpoints:

1. **`eu-corporate-kyb-clearance`**: Preflight statutory validation, certified KYB/UBO extraction, and Akoma Ntoso 3.0 statutory verification.
2. **`fiduciary-collateral-architect`**: Consolidated wealth verification, fiduciary covenant checks, and FIDO2 `WebAuthn` Step-Up safety.
3. **`akoma-zero-hallucination-counsel`**: Point-in-time `Akoma Ntoso 3.0 / ELI` statutory certification, non-quashing jurisprudence checks, and `SHA-256` + `RFC 3161` proof verification.
4. **`sovereign-regulatory-watch`**: Continuous compliance across EU AI Act, GDPR Art. 30 / Art. 12(3), CSRD ESRS iXBRL, NIS2/DORA, Construction Law No. 75-1334, and regulated CLE quotas.

## Quick Install (`npx`)

```bash
npx github:antica-labs/b2a-skills --target ~/.agents/skills
```

Or inspect available skills:

```bash
npx github:antica-labs/b2a-skills --list
```
